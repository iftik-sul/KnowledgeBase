## Workflow Stages

| Standard Service Pipeline | Column 2 | Column 3 |
| --- | --- | --- |
| Every regulated service follows this six-stage pipeline, with role hand-offs. |  |  |
| Stage | What happens | Owner |
| 1  Lodge | Applicant signs in (App / Web / Trustee Centre), selects the service, fills details and attaches documents. | Applicant role |
| 2  Validate | System checks completeness, statutory windows (e.g. 90-day off-plan), and pre-conditions (e.g. active escrow). | Platform / automated |
| 3  Audit | Regulator role reviews and approves, returns for correction, or rejects with reason. | Compliance / Licensing / Adjudication |
| 4  Pay | Fees and VAT computed automatically; settled via gateway, escrow deduction or card. | Applicant → Revenue & Finance |
| 5  Issue | Output document (e-certificate, title, contract, judgment) generated and delivered by e-mail / in-app. | Platform |
| 6  Record & Sync | Register updated; where relevant, data synced to State Lands Bureau via State Liaison. | State Liaison / Registry |
