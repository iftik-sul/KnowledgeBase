# Shared Component Library

**Proposed** — shared controls derived from Group C workflows.

## Components

* **Institution Operations Sidebar** — Dashboard, Applications, Documents, Settlement Account, Institution Profile and Notifications.
* **Progress Tracker** — Draft through Completed, including Pending Internal Certification and Returned by Certifier.
* **Application Table** — service, applicant, status, SLA, owner and actions.
* **Document Upload Table** — upload, replace, preview, version and validation result.
* **Decision Panel** — approve, return or reject with required reason.
* **Settlement Balance Card and Ledger Table** — balance, charge, credit, balance-after and linked application.
* **Permission Scope Chip** — file, certify and assisted-operator scopes.
* **Assisted-Mode Banner** — identifies operator and represented customer.
* **Audit Timeline** — filing, certification, review, settlement and output events.
