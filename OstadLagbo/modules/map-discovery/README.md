# Map Discovery Module (MAP)

Location capture (GPS/manual pin), map browsing, nearby search, filters, favorites, share links, and profile viewing. Serves both roles from one module.

The four layers derive in order — requirements → data model → api → ui ([project-standards](/OstadLagbo/project-standards.md)). Cross-cutting rules: [Data Model Overview](/OstadLagbo/data-model-overview.md), [API Overview](/OstadLagbo/api-overview.md), [UI Overview](/OstadLagbo/ui-overview.md).
