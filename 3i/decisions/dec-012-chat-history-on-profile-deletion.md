# Profile Deletion Removes That Profile's Chat Messages

> **Superseded by [3I-DEC-016](dec-016-deletion-removes-content-retains-record.md) on 2026-08-18.**
>
> Retained for history. Not a basis for implementation.
>
> The decision below was taken before its two consequences were examined: it contradicted FR-CHAT-14, which retains messages on *account* deletion, and it destroyed the moderation records that FR-CHAT-09 and FR-CHAT-10 require to be logged and reportable. DEC-016 resolves both by removing message content while retaining the record.

## Context

Deleting a profile removes progress, enrolments, and exam results, while issued certificates remain valid and publicly verifiable (FR-FAM-10). Chat is not mentioned.

A 13–17 learner may participate in chat directly under their own display name (FR-CHAT-08), so a deleted profile can have authored messages.

## Decision

**Messages authored by a deleted profile are removed.** Taken in review, 2026-08-18. Superseded the same day.

## Why It Was Reversed

**It contradicted the baseline.** FR-CHAT-14 retains messages on account deletion and anonymises authorship to "Deleted user". A 15-year-old may exist as an account or as a profile, so identical conduct would be preserved or erased depending on which shape they happened to have.

**It destroyed safeguarding evidence.** If a reported message were deleted with the profile, the report and the action taken would lose their subject — and profile deletion is available to the guardian of the profile that authored it.

The reasoning that was wrong is as useful as the reasoning that was right. This file stays.
